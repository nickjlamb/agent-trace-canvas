An agent trace you can actually see

An infinite, Miro-style canvas that renders an AI agent's run as a node-edge graph — every model call, tool call and retrieval, each scored by an eval. Replay one of three saved runs of the PubCrawl literature agent — in the lecanemab run, watch it draft an answer that overstates the clinical effect, and the eval catch it — or ask your own biomedical question and watch a real agent search the evidence and answer, live.
